# Source do decomp

Este diretório começa vazio de propósito: o M0 prepara o workspace e o M1
começa pelo boot/título/menus/texto.

Padrão planejado:

- assembly estruturado WLA-DX;
- um arquivo por banco/rotina, labels descritivos;
- dados e tabelas em arquivos separados, com comentários;
- `build/` contém objetos/ROM gerados e não é commitado;
- baseline final precisa reproduzir o ROM japonês byte-a-byte.

Não colocar ROM, assets originais, texto extraído do jogo ou C gerado aqui.
